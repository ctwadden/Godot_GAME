EXPERIMENT / SAME PRODUCT, SAME AUDIENCE

Who sees the advert?

Predict before running

One slot serves one advert to one profile. Eligible profiles may still miss an ad when slots run out. The declared interests are fictional audit evidence; the matching service never reads them.

Matching, ranking, outcomes and data-use assumptions

Eligibility

Broad: all 20 profiles.
Contextual: current page topic = product topic. Browsing consent is not required because history is not used.
Interest: consent = yes, most frequent active browsing topic = product topic, and that topic appears at least twice. Ties use music, cycling, coding, design order. Deleted events are ignored.

Ranking and possible outcomes

Broad/contextual use a seeded queue. Interest ranks by inferred-topic count, then the same queue. The first N eligible profiles receive an advert. A repeatable hash creates a click draw and purchase draw for each product/profile/seed.

For served profiles: simulated click probability is 0.55 when declared interest matches, otherwise 0.12. A simulated click has a separate 0.30 purchase probability. These are invented teaching assumptions, not measured effectiveness. A click is not a purchase guarantee.

Count inputs, not morality

Context reads 20 current-page topic fields. Interest reads 20 consent fields and every active browsing-topic field for consenting profiles. Broad reads none of these fields. Counts include inputs assessed even when no advert is served. One event topic = one field read. Declared-interest fields used by matching = 0.

These counts describe input use. Sensitivity, purpose, retention and control matter too. Contextual pages can themselves reveal sensitive subjects. The queue uses fictional IDs only; no real identifiers are collected.

Your session

  1. Watch the worked example, or classify the three item sales by buyer and seller roles.
  2. Choose a product, policy and slot limit. Make a prediction and run.
  3. Inspect each profile’s observed data, inference, rule and outcome. P04 has a deliberately incorrect inference.
  4. Pin a run as A. Change only policy and run B to compare fairly. Editing consent or a browsing event is a separate input-change experiment.
  5. Explain your evidence and a new opportunity-ad case. Download a report; it is not uploaded automatically.

Advertising can pay a platform’s costs so users do not pay directly. That funding arrangement does not make every use of data acceptable. Examine consent, manipulation, exclusion and alternatives.
